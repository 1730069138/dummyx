## J1 概率掉线专项记录

### 现象

- J1 在自动调零时概率性出现状态反馈过期，例如：状态 2.00-2.02 秒、位置约 0.15-0.30 秒。
- 视频中各节点曾出现循环在线/离线，而不是七个节点永久离线。
- 最小化只读查询中曾复现 J1 连续 5 次没有状态回复，说明不是单纯的 GUI 显示问题。

### CAN 实机诊断结果

- `can0` 使用 `gs_usb`，当前为 ERROR-ACTIVE。
- 接口设置为 1 Mbps 仲裁速率和 5 Mbps 数据速率。
- 主机当前发送的控制请求为 11 位标识符、最多 8 字节的经典 CAN 帧；总线接口本身开启 CAN-FD 接收能力。
- 实测电机回复：
  - J1-J6：CAN-FD，BRS 开启，数据段为 5 Mbps。
  - J7：经典 CAN，无 BRS，全程为 1 Mbps。
- CAN-FD 控制器允许经典 CAN 与 CAN-FD 帧共存，因此混合帧型并非必然不兼容；但帧型不一致会增加诊断复杂度。
- 主动查询期间捕获到 CAN 协议错误帧，主要为位填充错误。错误在多个节点通信时出现，不只发生于 J1。
- 5 Mbps 数据阶段对线束、接头、分支长度、终端电阻和地电位差远比 1 Mbps 敏感。

### 终端电阻测量

已完成的断电测量：

- USB-CAN 板单独测 CAN-H 与 CAN-L：约 120Ω。
- 机械臂线束单独测 CAN-H 与 CAN-L：约 4kΩ。
- USB-CAN 板连接机械臂线束后，整条总线测量：仍约 120Ω。

结论：USB-CAN 板上的 `120R TERM` 已生效，但机械臂物理远端没有有效的第二只 120Ω 终端，或者远端终端/线路断开。完整线型 CAN 总线两端各有一只 120Ω 时，断电总阻值应接近 60Ω。当前缺少远端终端很可能是 5 Mbps 下位错误和概率掉线的重要原因。

待处理硬件项：确认实际线束拓扑，在物理总线最远端（通常为最后一个串联关节）正确接入 120Ω、±1% 终端电阻，然后断电复测总线应约为 60Ω。终端不能接在 CAN 与 GND/24V 之间，也不能把两只终端都放在 USB-CAN 板一端。

### 已实施的软件抗掉线措施

1. 降低轮询负载
   - 常规轮询只高频请求必要的状态和位置。
   - 只有正在调零的关节高频请求位置、速度和电流。
   - 非活动关节的电流采用轮流抽样，避免同时大量查询。
   - CAN 查询之间增加间隔，减少瞬时总线拥塞。

2. 消除 J1 固定首节点偏差
   - 原轮询始终从 J1 开始，实测 J1 的回复数量明显较少。
   - 改为每轮旋转起始节点，避免某一个节点长期承担空闲后首个请求。
   - 修改后各节点回复数量明显趋于均衡。

3. 反馈老化重试
   - 状态或位置开始老化时执行额外的有界查询重试。
   - GUI 独立判断状态和位置年龄，避免丢一个状态帧同时废弃仍持续更新的位置反馈。

4. 调零运动指令重发（2026-09-13）
   - 原行为：状态帧达到 2 秒即失败，即使位置仍每 0.15-0.30 秒更新。
   - 新行为：自动调零期间，只要位置反馈仍新鲜，不再因为单独状态帧过期立即终止。
   - 在失能、故障复位和使能确认阶段，每 0.5 秒重发对应的幂等命令，最长等待 8 秒获得新的状态确认。
   - 在限位搜索和回退阶段，每 0.5 秒重发同一个位置目标，直到确认关节至少移动 0.2°。
   - 重发的是同一个目标，不连续累加目标，不生成不断扩大的运动距离。
   - 一旦确认已经运动，停止启动重发，由驱动器继续执行原目标。
   - 位置反馈也过期、CAN 断开、用户取消或任务达到超时时，仍会停止并进入软件锁定。
   - 限位搜索总超时保持 40 秒，防止通信异常时无限运动。

### 当前判断

- 软件轮询顺序曾放大 J1 的掉线概率，已经修复。
- 调零状态帧门槛过严导致位置仍新鲜时提前锁定，已经修复。
- 软件重试可以使偶发丢帧时的调零继续执行，但不能修复 CAN 物理层。
- 当前最重要的剩余问题是远端 120Ω 终端缺失；在完成终端修复前，CAN-FD 5 Mbps 错误仍可能出现。
- 不应盲目把所有主机请求改成 CAN-FD+BRS，也不应只修改电脑端数据速率；电机和主机必须使用一致配置。

## 2026-09-13：所有运行功能统一反馈过期重试

### 要求

- 不只自动碰撞调零，其他 GUI 功能遇到偶发状态反馈丢失时，也应重复发送幂等命令，避免在位置反馈仍正常时立即失败锁定。

### 统一行为

- 新任务开始前仍要求状态和位置反馈都新鲜，不允许在初始状态未知时启动运动。
- 任务开始后，如果状态反馈过期但位置反馈仍新鲜，认为节点通信仍存在，持续查询反馈并每 0.5 秒重发同一个目标或状态命令。
- 只有收到命令之后的新鲜状态和位置反馈，并确认实际到位/状态改变，任务才会完成；旧的“到位”或“已使能”标志不能作为成功依据。
- 如果位置反馈也超过 2 秒，立即终止并进入软件停止锁定。完全失去位置可见性时不会继续盲目发送运动目标。
- 所有重试仍受取消、软件锁定和任务总超时约束，不无限扩大目标或运动范围。

## 2026-09-13：J2 重姿态下调零回退超时

### 现象

- 自动碰撞调零在 J2 写零后的回位阶段失败并锁定。
- 错误信息：`J2 回退到 80° 超时`。
- 机械臂处于较重姿态时更容易显，J2 有运动目标但输出力矩不足以抬起负载。

### 根因

- J2 搜索机械限位时使用低碰撞电流 `4`，该参数适合受控触限。
- 整理后的 GUI 在写入零点后调用了同一套调零配置，导致回到 80° 时仍使用电流限制 `4`。
- 目标重发只能处理命令丢失，不能提高电机输出力矩；关节已经收到目标但承重能力不足时，重复目标不会解决问题。
- 项目原有自动调零工具明确采用：写零后恢复运行限流 `10`、过流保护 `12`、回退速度 `2`、回退加速度 `5`。GUI 整理时遗漏了碰撞阶段与承重回位阶段的参数分离。

### 修改

- 新增独立的调零后回位参数，不再复用低电流碰撞参数：
  - 回位/运行电流限制：10
  - 运行过流保护：12
  - 回位速度：2
  - 回位加速度和减速度：5
- 写零完成后先下发上述参数，再使能并回到各关节安全位置。
- 回位电流必须低于运行过流保护值，配置非法时 GUI 启动即拒绝。
- 事件记录会写明每个关节写零后的回位电流、保护电流、速度和加速度。
- 碰撞搜索电流保持各关节原有低值，因此没有提高撞击限位时的力度。

### 验证

- 新增回位参数顺序和值的自动化测试。
- 当前自动化测试由 32 项增加到 33 项，全部通过。
- 尚需在重姿态下实机复测 J2 能否稳定回到 80°，并观察电流、温升、过流标志和 CAN 错误帧。

- 关节状态表不再显示抽象的“反馈年龄”，改为“状态更新时间”和“位置更新时间”；未收到反馈时明确显示“尚未收到”。
- 更新时间由单调时钟接收时刻换算为本地带时区时间，便于与终端、录像和现场操作时间对照。
- 报警详情会保留事件发生时七个关节的状态快照、位置、电流、错误、最近目标，以及各类反馈更新时间。
- 增加报警类型筛选、最近持久化记录加载和“导出本次调试记录”。导出的 JSON 包含本次会话标识、总线健康状态、节点配置、当前状态与本次运行事件。
- 工作结束归位确认区域增加七关节进度表，逐项显示目标、当前位置和等待反馈/移动中/已到位；只有归位指令之后的新鲜反馈才能判定完成。

### 持久化与可靠性

- 日志按运行环境保存在 `runtime/logs/gui-events.jsonl`；虚拟模式保存在 `runtime/logs-virtual/gui-events.jsonl`。
- 单文件上限 5 MB，并保留 5 个历史轮转文件，避免日志无限占用磁盘。
- 每次启动生成独立会话标识；导出默认只包含本次运行仍留在轮转文件中的记录，避免混入之前的调试过程。
- 日志写入使用有界队列和后台线程，控制线程不等待磁盘 I/O；队列满或写盘失败会在界面提示。
- 刷盘和关闭均有时间上限。即使磁盘或日志线程异常，也不会无限阻塞 GUI 退出。
- JSON 中的无穷值和非法数值会转换为空值，确保调试文件可被标准工具读取。

## 2026-09-13：安全姿态归位、失能并终止程序

- “归位成功后退出”调整为“归位、确认失能后退出”。
- 严格执行顺序：到达七关节结束姿态并取得新鲜到位反馈 → 向全部关节发送失能 → 取得每个关节的新鲜失能反馈 → 关闭 GUI、CAN 接口并结束 `python run.py gui`。
- 失能指令按 0.5 秒间隔重复发送，单个关节反馈丢失时继续查询和重发；不使用发送前的旧失能状态作为成功依据。
- 任一关节在规定时间内没有确认失能，程序不会退出，并显示未确认的关节、保持软件锁定，方便继续检查现场状态。
- 退出确认区在第二阶段明确显示“正在确认失能”，不会把正常的失能锁定误显示成归位失败。
- “不归位，直接退出”保留为明确的人工旁路，不主动失能。
- 新增失能新反馈确认和反馈未确认重发测试。
- 结束归位以每个关节的新鲜实际位置作为最终依据，允许目标 ±1°；不再额外依赖驱动器可能未及时置位的 `target_reached` 标志。普通运动仍保留该标志检查。
- 当前自动化测试共 41 项，全部通过。
- 根据结束姿态现场反馈更新目标：J5 调整为 119.622°，J6 调整为 140.037°；J1、J4、J7 四舍五入后与原目标一致。J2 和 J3 的截图位置超出当前软限位，因此按要求保持 2°、-180° 不变。
